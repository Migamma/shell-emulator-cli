# shell-emulator-cli

Эмулятор командной оболочки UNIX-подобной ОС, написанный на Java.
Учебная практическая работа по дисциплине конфигурационного управления, вариант 7.

## Общее описание

Программа работает в терминале в режиме REPL: показывает приглашение к вводу,
читает команду, выполняет её и выводит результат. Работа эмулятора максимально
приближена к работе в командной строке UNIX.

Текущий этап: **этап 1 (REPL)**. Команды ls и cd пока являются заглушками.

## Функции и настройки

### Приглашение к вводу

Формируется из реальных данных ОС в формате `username@hostname:~$`.
Если имя хоста определить не удалось, используется `localhost`.

### Переменные окружения

Перед выполнением команды переменные вида `$NAME` заменяются значениями
из окружения реальной ОС. Неизвестные переменные заменяются пустой строкой.

### Команды

| Команда | Описание |
|---|---|
| `ls [аргументы]` | заглушка: выводит своё имя и полученные аргументы |
| `cd [путь]` | заглушка: выводит своё имя и аргумент; принимает не больше одного аргумента |
| `exit` | завершает работу эмулятора; аргументов не принимает |

Работа также завершается при конце ввода (Ctrl+D).

### Обработка ошибок

| Ситуация | Сообщение |
|---|---|
| неизвестная команда | `имя: command not found` |
| лишние аргументы у cd или exit | `cd: too many arguments` |
| после подстановки переменных не осталось команды | `no command after variable expansion` |

После ошибки эмулятор продолжает работу.

## Сборка и запуск

Требуется Java 17 или новее и Maven.

Сборка:

```
mvn package
```

Запуск:

```
./run.sh
```

Скрипт собирает проект и запускает эмулятор.

### Тесты

На этапе 1 автоматических тестов нет, проверка выполняется вручную
по примерам ниже. Тестовые скрипты будут добавлены в папку `tests`
на следующих этапах.

## Примеры использования

```
ivan@laptop:~$ ls -l /tmp
ls: args: -l /tmp
ivan@laptop:~$ cd $HOME
cd: args: /home/ivan
ivan@laptop:~$ cd
cd: args: no argument
ivan@laptop:~$ cd a b
cd: too many arguments
ivan@laptop:~$ pwd
pwd: command not found
ivan@laptop:~$ $NOSUCHVAR
no command after variable expansion
ivan@laptop:~$ exit 5
exit: too many arguments
ivan@laptop:~$ exit
```
